NOTA: los números delante de los nombres de las carpetas son solamente para tu referencia, en la computadora no existen esos números

La carpeta 1.01 basesdatos\ es para guardar en ella todos los archivos .dart relacionados con las bases de datos
La carpeta 1.02 errores\ es para guardar en ella todos los archivos .dart relacionados con los errores
La carpeta 1.03 idiomas\ sirve para guardar en ella los textos en español y en otro idioma (francés, inglés, etc.)
La carpeta 1.04 inicio\ es para guardar en ella la pantalla de login y la pantalla principal de la aplicación
La carpeta 1.05 preferencias\ sirve para guardar en ella todas las preferencias del usuario
La carpeta 1.06 temas\ es para guardar en ella todos los archivos .dart relacionados con los colores, espacios, estilos de texto, layout, radios, temas claro y oscuro
La carpeta 1.07 utilitarios\ es para guardar en ella todos los archivos .dart relacionados con funciones y clases de utilidad general, o sea que podrían utilizarse por cualquier otro archivo .dart
La carpeta 1.08 validaciones\ es para guardar en ella todos los archivos .dart relacionados con las validaciones. Habrá dos archivos .dart para las validaciones: can_validar.dart y cap_validar.dart, se usará can_validar.dart cuando para validar se requiera acceso a la Base de Datos, por ejemplo para saber si el cliente existe o para obtener los datos del cliente; se usará cap_validar.dart cuando no se deba acceder a la Base de Datos, por ejemplo para comprobar que la fecha corresponde al año actual
La carpeta 1.09 varios\ es para guardar en ella todos los archivos .dart que no entran en otras carpetas, por ejemplo para un formulario de prueba de controles o widgets
La carpeta 1.10 widgets\ es para guardar en ella todos los archivos .dart que corresponden a widgets creados por nosotros

La carpeta 2.1 hasta 2.9 son para guardar en ellas todos los archivos .dart que corresponden a esas opciones del drawer

La carpeta 3. rutas\ es para guardar en ella todas las rutas utilizadas en la aplicación
